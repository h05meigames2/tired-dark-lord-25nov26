# The Tired Dark Lord: A 100-Word Villain Monologue

Entry program for the [make.fun bounty "The Tired Dark Lord: A 100-Word Villain Monologue"](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) ($2 in USDC).

`main.py` writes a single ~100-word monologue from Lord Ashenmar, Dark Lord of the Tower of Ashes — thirty years on an uncomfortable throne, an eclipse ritual forever postponed, heroes who always arrive at the worst hour — to `/output/entry.txt`. His exhaustion shows only in pauses, postponements and deflections; the apocalypse itself gets saved for tomorrow.

## Run

```bash
python3 main.py
```

This writes the monologue to `/output/entry.txt` (UTF-8, 1–600 characters, no trailing newline).
